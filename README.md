# Josue App - Task Manager

A responsive task manager web app built with HTML, CSS, and JavaScript.

## Live Demo
https://josuemutsiirwa.github.io/Josue-app/

## Features
- Add tasks with text, money, and date
- Mark tasks as completed / not completed
- Edit and delete tasks
- Filter: All, Completed, Not Completed
- Dynamic totals by filter
- Data saved in localStorage
- Responsive design (mobile, tablet, desktop)
- PWA support (manifest + service worker)

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure
- index.html
- tasks.html
- style.css
- script.js
- tasks.js
- manifest.json
- service-worker.js
- icons/
